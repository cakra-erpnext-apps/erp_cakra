# agent_email — pengetahuan agent email customer

Semua file .md di folder ini dimuat ke agent email (fleet.auto_reply_to_inbound) sebagai
PANDUAN: jenis pertanyaan customer dan cara tim CS menjawabnya. Bukan sumber data:
angka, tanggal, harga di contoh TIDAK boleh disalin ke balasan; fakta tetap dari DATA DOKUMEN.

Format per jenis pertanyaan:

## <Jenis pertanyaan>
- Contoh kalimat customer: ...
- Cara CS menjawab: ... (pola/template, sebut data apa yang dipakai)
- Topik aturan: RECEIPT / STATUS / DOCUMENTS / SCHEDULE / THANKS / LAIN (LAIN = selalu review user)
